# IPL TICKET BOOKING
Creating an IPL ticket booking website as a part of web-development activity. This 
project aims provide a simple interface where users can view IPL match schedules and access a ticket booking.

# Technologies used:
HTML - To create the structure and content of the website.
CSS - Used for styling and making the website visually attractive.
JavaScript - Used to make the website more interactive.
VScode - To write and edit the code.
GitHub - To upload, manage and maintain the files
